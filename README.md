## 🚀 About The Project

The **Community Surplus Food Donation Platform** connects surplus food donors directly with community recipients, volunteer logistics drivers, and food banks. Built with a high-performance **React Native (Expo)** mobile frontend and a **Node.js Express** backend, it streamlines food rescue, reduces food waste, and simplifies verification across 5 distinct user roles.

<br/>

### 🏛️ Key Architectural Pillars

| Pillar                           | Description                                                                                                                |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 📱 **Cross-Platform Mobile App** | Dynamic mobile and web interface powered by Expo Router with `AuthContext` for seamless persistent JWT session management. |
| 🛡️ **Role-Based Access Control** | Explicit separation of workflows for **Donors**, **Recipients**, **Drivers**, **Food Banks**, and **Admins**.              |
| ⚡ **RESTful API & Database**    | Scalable Node.js Express architecture integrated with MySQL Workbench pool connections and bcrypt password security.       |

## ✨ Features

- 🍲 **Donor Dashboard**: Post surplus food items with expiry times and pickup locations
- 🙋 **Recipient Portal**: Browse nearby food listings and claim available reservations
- 🚚 **Driver Logistics**: Accept pickup & delivery tasks with driver license verification
- 🏢 **Food Bank Platform**: Manage bulk donation requests and public distribution spots
- 📊 **Admin Control Center**: Approve drivers and food banks, manage active food items, and oversee system analytics
- 🔒 **Secure Auth**: JWT authentication with automatic role-based navigation redirects

<br/>

## 👥 Role Division & Management

| Role             | Mobile Responsibility                         | Admin Sub-Panel                                             |
| ---------------- | --------------------------------------------- | ----------------------------------------------------------- |
| 🍏 **DONOR**     | List food items, quantities, and pickup times | **Donations Admin**: Manage listings & remove expired items |
| 🤲 **RECIPIENT** | Browse food feed & make claims                | **Claims Admin**: Resolve disputes & monitor deliveries     |
| 🚚 **DRIVER**    | Accept pickup & delivery orders               | **Driver Verification**: Review licenses & approve accounts |
| 🏢 **FOOD_BANK** | Request bulk donations & manage outlets       | **Organization Admin**: Verify & approve registered NGOs    |
| ⚙️ **ADMIN**     | System overview & multi-panel access          | Full Platform Admin Console                                 |
